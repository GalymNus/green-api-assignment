# green-api-assignment (React + TypeScript + Vite)


## Описание:
Данный проект собран с использованием Vite, React и TypeScript. Проект является чатом через сервис [GreenAPI](https://green-api.com).


## Функционал:
* получение списка чатов
* получение истории сообщений из конкретного чата
* отправка сообщений
* создание нового чата
* получение новых сообщений


## Для работы нужно знать\иметь\проверить:
* **idInstance** и **apiTokenInstance** оба получаются из настроек инстанса на сайте [GreenAPI](https://green-api.com)
* Обязательно сверьте свой хост в apiUrl(src/consts.ts). 
* Поле вебхука должно быть пустым
* Получение входящих сообщений должно быть включено в настройках инстанса.
* формат номера: 79991234567 (без символов и пробелов)


## Запуск проекта:
Установка нужных пакетов:
```bash
npm i
```

Запуск:
```bash
npm run dev
```
